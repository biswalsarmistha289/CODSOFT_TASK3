# CODSOFT Task 3 – Password Generator

## About
This is a Python-based Password Generator developed as part of my CodSoft Python Programming Internship.

The program generates random passwords using:
- Uppercase letters
- Lowercase letters
- Numbers
- Special characters

## Features
- Allows users to choose password length
- Generates random passwords
- Includes different character types
- Simple and beginner-friendly command-line interface

## Technologies Used
- Python

## How to Run
1. Make sure Python is installed.
2. Download or clone this repository.
3. Open the project folder in VS Code.
4. Run the following command:

```bash
python password_generator.py
```
